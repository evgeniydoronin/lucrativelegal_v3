## Список проблем

### 🎲 GSAP & Анимации

#### [Hero 3D Cube Positioning Fix](./HERO_CUBE_POSITIONING_FIX.md)
**Статус:** ✅ Решено  
**Дата:** 14.07.2025  
**Компонент:** Hero 3D Cube Animation  

**Проблема:** Куб "прыгал" при переключении между fixed и absolute режимами позиционирования, иногда полностью исчезая с экрана.

**Корневая причина:** Смешивание систем координат GSAP - одновременное использование `x/y` и `xPercent/yPercent` приводило к двойному позиционированию.

**Решение:** Разделение ответственности - CSS для базового позиционирования, GSAP только для центрирования с использованием `clearProps`.

**Ключевые уроки:**
- Никогда не смешивать `x/y` с `xPercent/yPercent` в GSAP
- Всегда использовать `clearProps` при переключении режимов
- Разделять CSS и GSAP ответственность для сложного позиционирования
