# 🔧 Рефакторинг кодовой базы - Анализ и план исправления

## 🚨 Основная проблема

В процессе разработки выявлены критические проблемы производительности, которые **блокируют добавление новых GSAP анимаций** и вызывают серьезные тормоза в некоторых секциях сайта.

## 📊 Статистика проблем

- **164 вызова** GSAP ScrollTrigger в компонентах
- **209 дублированных паттернов** в SCSS файлах  
- **700+ строк кода** в одном компоненте (hero-cube.js)
- **85+ обработчиков событий** с дублированием
- **45+ дублированных методов** в компонентах
- **13 компонентов** без единой архитектуры
